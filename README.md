# Logistic Regression Optimizers for SMS Spam Classification

This project implements Logistic Regression to classify SMS messages as Ham or Spam using the SMS Spam Collection Dataset.

Five optimization algorithms are implemented and compared:

1. Gradient Descent (GD) with Momentum
2. Stochastic Gradient Descent (SGD) with Momentum
3. Mini-batch Gradient Descent with Momentum
4. RMSProp with Momentum
5. Adam with Momentum

The models are evaluated using Accuracy, Precision, Recall, F1 Score, Binary Cross-Entropy Loss, and Confusion Matrices.

The project was developed using Python on Kaggle Notebooks.
